# 2026-07-01 09:13 - Add answer page "What is MODBUS RTU-over-TCP"

The user asked "What is MODBUS RTU-over-TCP". The wiki had no page on this variant.
RTU-over-TCP is not defined in any of the official MODBUS Organization specifications
in `raw/MODBUS/`; it is a vendor-introduced convention that wraps a complete MODBUS RTU
serial frame (including its CRC-16) inside a TCP connection without the standard MBAP
header.

Because it is not in the specs, the new answer page explicitly states this up front,
marks non-spec claims as "(convention, not in specs)", and grounds every official
statement (MODBUS TCP, MODBUS RTU, MBAP, CRC-16) in the existing spec-derived concept
pages. The page explains the frame layout, how it differs from official MODBUS TCP and
MODBUS RTU, its interoperability consequences (no MBAP header, retained CRC, no
Transaction ID, single outstanding request), and how to recognize it on the wire.
